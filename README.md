# Life

A personal app that keeps budget, savings and subscriptions in one place, in a calm pastel bento design. It works on a phone (add it to the home screen) and on a computer.

Your budget, savings and subscriptions are saved in your own private database behind your login. The code in this repo is public.

## Make your own copy

Give your Claude agent this request:

> Set up my own copy of the Life app by following docs/BUILD-GUIDE.md in https://github.com/Katri-Buyte/life

The guide walks it through copying the code, replacing the personal content, creating your own Supabase database and login, testing, and publishing on GitHub Pages. You will need a GitHub account and a free Supabase account, and you will choose your own passwords; the agent will stop and ask you at those steps.
